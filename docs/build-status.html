The dataset

Synthetic, deterministic, seeded into Supabase

90Days history

There is no public dataset that pairs spare-parts consumption with supplier pricing, lead times and reliability — that data is commercially sensitive and nobody publishes it. So this is generated, from a fixed random seed, modelled on industrial MRO procurement patterns. Say that plainly to judges; it is a normal answer, and the generator is more defensible than a hand-written CSV.

What the generator models

  • Weekly rhythm. Weekend shifts run at 35% of weekday consumption.
  • Genuine failure spikes. Three parts jump 3–5× in the final five days — what the anomaly agent must catch.
  • Correlated suppliers. A tier variable drives price, lead time, reliability and defect rate together, so cheap vendors really are slower and worse. Without that correlation the ranking agent has nothing to weigh.
  • Deliberate risk cases. 13 parts sit below their reorder point; 5 are single-sourced.

The dashboard

React + Vite · running at localhost:5173

What it does now

  • Part picker across all 40 parts, flagging the 13 below their reorder point.
  • Agent cards reveal one at a time so the pipeline reads as live, each showing its metrics and its reasoning.
  • Supplier ranking table with the selected vendor highlighted.
  • On escalation, the top two ranked options the approver actually needs.
  • Closing panel: manual vs. agent cycle time, cost avoidance, and the LLM-written summary.

Worth knowing

Decisions and open edges

No agent decision depends on an LLM

All four agents compute their decisions in plain JavaScript. Groq writes only the closing summary paragraph, and falls back to a deterministic template if the API is unreachable. The demo cannot fail live because of a network hiccup.

Bugs found and fixed while wiring the data

  • Truncated history. PostgREST caps responses at 1,000 rows — only 1,000 of 3,600 usage records were loading, silently corrupting every baseline. Now paged.
  • Blind anomaly detector. Weekend dips inflated baseline variance enough to hide a 5× spike. Switched to a standard-error test; it now catches all three.
  • Degenerate scoring. Min–max normalisation forced a 100-vs-0 split whenever a part had two suppliers. Now scored on absolute scales.
